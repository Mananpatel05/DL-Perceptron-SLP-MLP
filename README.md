## Aim
To implement Single Layer Perceptron and Multi-Layer Perceptron (MLP) from scratch and analyze their performance on linear and non-linear datasets.

---

## Tools Used
- Python
- NumPy
- Matplotlib
- Jupyter Notebook (Anaconda)

---

## Tasks Completed

### Task 1: Single Layer Perceptron
- Implemented from scratch
- Trained using learning rule
- Visualized decision boundary

### Task 2: Multi-Layer Perceptron
- Input Layer: 2 neurons
- Hidden Layer: 4 neurons (ReLU)
- Output Layer: 1 neuron (Sigmoid)
- Implemented backpropagation

### Task 3: Analysis
- Compared Perceptron vs MLP
- Tested on XOR dataset
- Studied hidden layer size (2,4,8)
- Plotted training loss

## How to Run

1. Open Anaconda Navigator
2. Launch Jupyter Notebook
3. Open `DeepLearning_SLP_MLP.ipynb`
4. Run all cells


---

## Results
- Perceptron works well on linear data
- Fails on XOR
- MLP successfully learns XOR
- Larger hidden layers improve learning

---

## Conclusion
This experiment demonstrates the importance of hidden layers and backpropagation in solving non-linear problems.
